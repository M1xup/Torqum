# TORQUM — Telegram Mini App магазин цифровых продуктов

Тёмная премиальная витрина: бот на aiogram 3 + FastAPI-бэкенд + Mini App (SPA) + админ-панель + оплата через RollyPay.

## Структура

```
├── main.py              # единая точка входа: uvicorn + polling
├── config.py            # переменные окружения
├── db.py                # SQLite (aiosqlite): товары, заказы, настройки
├── security.py          # проверка подписи Telegram initData
├── payments.py          # интеграция RollyPay API + проверка подписи вебхуков
├── bot.py               # команды бота (/start, /admin, /purchases) и выдача товаров
├── routes.py            # API: витрина, корзина/checkout, покупки, админка, вебхук
├── static/
│   ├── index.html       # Mini App: главная, каталог, корзина, о нас, мои покупки
│   ├── admin.html       # админ-панель (товары, тексты, заказы)
│   ├── policy.html      # политика конфиденциальности
│   └── terms.html       # пользовательское соглашение
├── requirements.txt
└── Dockerfile
```

## Переменные окружения (Bothost → настройки бота)

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `DOMAIN` | домен из панели Bothost (подставляется автоматически) |
| `ADMIN_USERNAMES` | username'ы админов через запятую: `M1xup,unclued` |
| `SUPPORT_CONTACT` | контакт поддержки: показывается в Mini App, на /policy и /terms |
| `ROLLYPAY_API_KEY` | api_key кассы (заполнить позже) |
| `ROLLYPAY_SIGNING_SECRET` | секрет подписи вебхуков кассы (заполнить позже) |
| `ROLLYPAY_TEST_MODE` | `true` — тестовые платежи (sandbox), `false` — боевые |

## Деплой на Bothost

1. Залейте проект на GitHub (или zip-архивом в панель).
2. Создайте бота, укажите репозиторий, токен, включите галку **«Использовать собственный Dockerfile»**.
3. Назначьте домен — SSL выпустится автоматически, `DOMAIN` придёт в окружение.
4. Добавьте остальные переменные окружения из таблицы выше.

## Админ-панель

- В боте команда `/admin` — открывает отдельную страницу `/admin` (кнопка «Открыть админ-панель» ведёт именно туда).
- Доступ имеют только username из `ADMIN_USERNAMES`. Обычным пользователям команда `/admin` не показывается: её нет в меню команд бота и в тексте `/start`, а при прямом заходе на `/admin` страница отвечает «Доступ ограничен».
- В панели: товары (создание/редактирование/удаление, цена, количество, описание, категория, тип «текст» или «файл», картинка по URL, флаги «Популярный» / «TORQUM Select»), тексты главной и «О нас», контакты поддержки, категории, список всех заказов.

**Страница товара:** у каждого товара в Mini App есть отдельная страница (`#product/<id>`): название, цена, наличие, описание и кнопка «В корзину». Название, цена и описание заполняются в админ-панели.

**Количество товара:** `-1` = без ограничений, `0` = нет в наличии (скрыто из каталога в плане покупки, карточка покажет «Нет в наличии»).

**Файлы:** в поле «Содержимое» для типа «файл» укажите прямую ссылку на файл (например, ссылку с диска/CDN). После оплаты бот пришлёт файл как документ (или ссылку, если Telegram не смог скачать).

## RollyPay — что сделать при подключении кассы

1. Укажите в настройках кассы **callback_url**: `https://ВАШ_ДОМЕН/webhooks/rollypay`
2. Заполните переменные `ROLLYPAY_API_KEY` и `ROLLYPAY_SIGNING_SECRET` в окружении Bothost и перезапустите бота.
3. Для проверки оставьте `ROLLYPAY_TEST_MODE=true` — платежи создаются с `"test": true`, реальные деньги не списываются. Для боевого режима — `false`.
4. Оплата: корзина → «Оплатить» → открывается `pay_url` → клиент платит по СБП → вебхук `payment.paid` → бот присылает товар в чат, товар появляется в «Моих покупках».

Вебхук проверяет подпись `X-Signature` (HMAC-SHA256 от `timestamp + "." + body`), обрабатывает `paid / canceled / expired / refunded / chargeback`, идемпотентен (повторная выдача исключена) и учитывает поздние исходы банка.

## Примечания

- Данные хранятся в SQLite-файле `torqum.db` внутри контейнера: при пересборке деплоя товары/настройки сохраняются, если платформа не пересоздаёт контейнер. Для надёжности позже можно перенести на внешний volume/БД.
- Политика конфиденциальности и соглашение доступны по адресам `/policy` и `/terms`, контакты поддержки на этих страницах подтягиваются из админ-панели автоматически.
- Поддержка по умолчанию: `torqumbot@gmail.com`. Контакт поддержки меняется в админ-панели (раздел «Контент»).
- После оплаты в корзине отображается детализация: каждый товар, количество, цена и итог — эта же информация передаётся в `description` и `metadata` платежа RollyPay.
